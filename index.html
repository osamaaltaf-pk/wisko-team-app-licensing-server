🚀 About Omni Sketches

Omni Sketches converts any image into a whiteboard sketch animation video, fully offline. Available for Windows, Android (APK) and as a browser web app.

✨ Product Features

  • Offline Rendering — Generates whiteboard sketch videos fully offline (Windows, Android, Web).
  • Rich Hand Library — 22 drawing styles across diverse demographics (kids, adults, elders, light/dark skin).
  • Interactive Controls — Precision sliders for animation speed, frame rate, and skip-rates.
  • Colorization — Option to transition into full-color image at the end of the whiteboard drawing.
  • Batch & Sequential Processing — Queue multiple sketch animations to run sequentially.
  • Auto Pen-Tip Detection — Algorithmic calculation of pen nib offsets for exact canvas alignment.

📦 How to Issue a License

  1. Choose the buyer's plan from the dropdown
  2. Set validity days (30 = monthly, 365 = yearly)
  3. Set credits = generations allowed per month
  4. Click Generate Activation Code
  5. Copy the OMNI-SK-… key and send to the buyer
  6. Buyer enters it on first app launch to activate
